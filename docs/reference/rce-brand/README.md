# RCE-huisstijlbronnen

Deze map bevat de oorspronkelijke huisstijl- en logobestanden die als
ontwerpbron voor Doorzoeker worden bewaard:

- `RCE Stijlgids Web.pdf`: webstijlgids;
- `RO_OCW_RCE_Logo_2_7462C_pos op wit_x_nl.eps`: drukwerkbron van het logo;
- `logo-rijksoverheid.svg`: vectorbron van het Rijksoverheidslogo.

Bestanden die de applicatie daadwerkelijk serveert staan in `public/`. Plaats
geen tweede runtimekopie in de repository-root.
