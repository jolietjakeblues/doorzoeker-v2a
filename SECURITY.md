# Beveiliging

## Ondersteunde versie

Alleen de code op `main` en de actuele publieke reviewversie worden bijgehouden.
Oudere commits en lokale kopieën krijgen geen afzonderlijke beveiligingsupdates.

## Een kwetsbaarheid melden

Meld een mogelijk beveiligingsprobleem niet in een openbare issue. Gebruik
hiervoor **Report a vulnerability** op het tabblad **Security** van deze
repository. Beschrijf wat er gebeurt, hoe het te reproduceren is en welke
gegevens of gebruikers geraakt kunnen worden.

Je krijgt zo snel mogelijk een eerste reactie. Publiceer details pas nadat het
probleem is onderzocht en, waar nodig, een oplossing beschikbaar is.
